# Loom Code v0.1.0

The first public preview of Loom: a local JavaScript coding agent with a terminal UI and a self-implemented orchestration core. Distributed as source under the MIT License.

## Install

Requires Node.js >=22.19.0 and pnpm 12.4.1.

```sh
git clone --branch v0.1.0 https://github.com/crapthings/loom-code.git
cd loom-code
pnpm install --frozen-lockfile --ignore-scripts
pnpm add --global "$PWD" --ignore-scripts
export AI_GATEWAY_API_KEY='YOUR_VERCEL_GATEWAY_KEY'
cd /path/to/project
loom
```

The default route is Vercel AI Gateway with `deepseek/deepseek-v4.1-flash`. Use `loom --demo` for an offline run without credentials. See the [README](https://github.com/crapthings/loom-code#readme) for PATH setup and provider overrides.

## Included

- Durable sessions, steering and queued inputs, shared budgets, interruption, and explicit crash recovery.
- File inspection, version-checked edits, checkpoints, shell execution, and output artifacts.
- Streaming TUI, approval dialogs, and `/mode` / `/permissions` selection.
- Read-only research/review subagents, lazy project skills, and context compaction.
- Headless JSON events and reusable core exports.

Loom implements the execution loop itself. Pi supplies model-protocol adapters and terminal UI components.

## Validation and limits

- 46 behavioral tests, Standard Style checks, and packed CLI/SDK smoke checks.
- GitHub CI covers Linux and macOS with Node.js 22.19.0 and 24.
- A clean local clone passed frozen dependency installation and offline package smoke checks.
- Automated checks use fake providers and local HTTP servers; live-provider acceptance is separate.

**Host shell execution has no OS sandbox.** The default `ask` mode prompts for writes and commands; `edit` automates file edits; `auto` automates both file writes and host commands; `plan` is read-only. Session data under `.loom/` may contain private workspace content and must not be committed.

MCP, persistent OAuth, executable plugins, distributed coordination, Windows validation, and npm registry publication are not included in this preview. Dependency catalog metadata and estimated prices can differ from the gateway's current limits and billing.
